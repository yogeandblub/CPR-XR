## 3. Root cause of most of tonight's failures: iCloud Drive eviction

- `~/Documents` is synced to iCloud Drive with "Optimize Mac Storage". The disk had only 12–17 GB free, so macOS kept replacing local files with cloud **placeholders** ("dataless" files).
- Renaming folders to `.nosync` **did not stop this** on this Mac: files inside `CPR-XR.nosync` were still evicted.
- Reading a placeholder makes the process wait for a download. This caused:
  - Unity freezing on open or compile (bee_backend idle, Editor waiting on file reads). This happened several times.
  - Gradle build failures from iCloud " 2"/" 3" duplicate files (an earlier session).
  - **Calls failing with "Call problem — check Wi-Fi":** Python's `requests` stalled reading files in the evicted env, and SignalWire connections failed with `SSLError` (03:30, 03:33). Plain `curl` to SignalWire worked, which proved the network was fine.
  - The scene file being a placeholder during the 03:42 build (see §2).
- How to check: `find <dir> -flags +dataless | wc -l` (any number above 0 means evicted files).
